# PlacePrep Web

React, TypeScript, and Vite candidate experience. The Vite development server proxies `/api` requests to the Express API on port 4000.

Run `npm run dev --workspace @placeprep/frontend` from the repository root. The production build is generated by `npm run build --workspace @placeprep/frontend`.

Implemented screens include the candidate dashboard shell, sign-in, registration, password recovery, and a resume upload/report workspace. Dashboard sample metrics are labeled as illustrative until connected to candidate data.
